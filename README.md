## Projects

### 🧾 [BookkeepGenie](https://github.com/AndrewLocke-pm/bookkeepgenie)
AI-powered bookkeeping with a 5-layer transaction enforcement system — rules-first classification, LLM fallback for edge cases, human confirmation modal, server-side enforcement, and database constraints as the last line of defence. Includes a 33-test automated suite with a pre-deploy gate.

> `LLM APIs` `AI enforcement patterns` `automated testing` `financial domain`

---

### 🧠 [AndrewOS](https://github.com/AndrewLocke-pm/andrewos)
A personal operating system built around a Goals → Initiatives → Challenges → Experiments loop. The AI layer reads your identity, a compressed memory of recent weeks, and active challenges to generate a specific weekly focus — not a generic to-do list.

> `context assembly` `memory compression` `AI planning` `TypeScript` `PostgreSQL`

---

### 🎙️ [StrikeCRM](https://github.com/AndrewLocke-pm/strikecrm)
A B2B CRM API with a full AI pipeline: create a voice note → transcribe via Scribe v2 → GPT-5 extracts structured deal updates → human reviews and applies to the deal record. Includes a deal state machine, multi-tenant org isolation, RBAC, and an immutable audit log.

> `voice AI` `transcription` `LLM extraction` `deal state machine` `multi-tenant` `TypeScript`

---

### 🔍 [HuntPrice](https://github.com/AndrewLocke-pm/huntprice)
Upload a PDF or image and get structured price data extracted automatically. AI document parsing with data visualisation — built for a South African property market use case.

> `document AI` `PDF parsing` `price extraction` `data visualisation`
